Cipher Chest

Cipher Chest is a C++ cryptography toolkit that implements multiple classical and custom encryption techniques using Object-Oriented Programming, Data Structures, STL containers, and File Handling.
The project provides a menu-driven interface where users can encrypt and decrypt messages using different ciphers, save results to a file, and view previously saved history.

---

Features

Implemented Ciphers
* ASCII Cipher
* Mirror Cipher
* Morse Cipher
* Caesar Cipher
* Atbash Cipher
* Vigenère Cipher
* Affine Cipher
* Stream Cipher
* Custom Mapping Cipher
* Chain Cipher (Circular Doubly Linked List Based)

Additional Features
* Encrypt and Decrypt messages
* Save results to file
* View saved history
* Menu-driven interface
* User-defined mappings for custom ciphers

---

Concepts Used

Object-Oriented Programming
* Inheritance
* Polymorphism
* Abstract Base Classes
* Virtual Functions
* Constructors and Destructors

Data Structures & STL
* Maps
* Stack
* Circular Doubly Linked List (CDLL)

File Handling
* Save encrypted/decrypted messages
* View previously saved history

---

How to Run

Compile:
g++ main.cpp -o CipherChest

Run:
./CipherChest

---

Highlights
* Uses a common abstract Cipher base class.
* Demonstrates runtime polymorphism through virtual functions.
* Includes a custom Chain Cipher implemented using a Circular Doubly Linked List.
* Supports saving and viewing cipher history through file handling.
